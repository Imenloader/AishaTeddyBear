## 2026-08-23 - [Async useEffect + WebSocket Reconnect = Unmounted State Updates]
**Bug Pattern:** When a useEffect creates a WebSocket AND an async visibility-change handler that does fetch(), the cleanup function only closes the original ws reference. But connectWebSocket() reassigns the local ws variable on reconnect - meaning a reconnected WebSocket is never closed on unmount. Furthermore, the async fetch can resolve after unmount, calling setLiveMessage/setBearState on an unmounted component.
**Resolution:** Added an isMounted boolean guard checked: (1) at the top of onmessage, (2) at the top of handleVisibilityChange, (3) after every await in the async handler. Set isMounted=false in cleanup.
**Prevention:** Any useEffect with async operations or reconnectable resources needs an isMounted guard. The pattern is: let isMounted=true in the effect body, check it after every await, set it false in cleanup. For reconnectable WebSockets, consider using a ref instead of a local variable so cleanup always closes the latest instance.
